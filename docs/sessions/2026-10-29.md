## Decisions
- Match on the localized string currently displayed, plus exact year → visitors see the same grouping
  in the active language, and events from different decades never collapse together.
- Merge only across distinct categories; repeated same-category events remain independent cards.
- Combine galleries in event order and deduplicate exact image URLs → images stay predictable and a
  shared URL does not create a repeated slideshow slide.
